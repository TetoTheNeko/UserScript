# 力扣提交结果音效（通过 / 未通过）

[Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/605331) · [GitHub 备用安装](https://raw.githubusercontent.com/TetoTheNeko/UserScript/main/LeetCode-Verdict-Sound.user.js) · [查看源码](../LeetCode-Verdict-Sound.user.js) · [反馈问题](https://github.com/TetoTheNeko/UserScript/issues/new/choose)

给每一次尝试一点回应，让刷题多一点动力。

本脚本为力扣的运行与提交结果添加声音反馈：通过时播放成功音效，未通过时播放提醒音效，排队和判题中保持安静。支持内置音色、自定义音频链接和本地音频，可以为两种结果分别搭配喜欢的声音。

当前版本：**2.1.0**。作者：**IAmTeto / TetoTheNeko**。

## 主要功能

- **结果音效**：明确通过时播放成功音，答案错误、编译错误、运行错误、超时等明确结果出现时播放提醒音；排队与判题中保持安静。
- **内置音色**：提供清脆的成功和弦与柔和的未通过提示音，由脚本生成，无需另外下载音频。
- **自定义音频**：通过与未通过可分别使用音频链接或导入本地文件，支持试听。
- **独立开关**：提供音效总开关，以及通过与未通过音效的独立开关。
- **音量调节**：支持 `0–100%` 调节，默认 `80%`，可一键恢复默认设置。
- **设置保存**：修改后自动保存；支持相应功能的脚本管理器可在同一脚本的标签页之间同步配置。

适用于力扣中国站 `leetcode.cn` 与国际站 `leetcode.com` 的题目页面。实际识别效果取决于当前页面的操作按钮、结果面板与文案；网站改版、竞赛页面或不同编辑器布局可能需要适配。

## 安装与设置

1. 通过 Tampermonkey（篡改猴）安装脚本，并刷新已打开的力扣页面。
2. 正常点击「运行」或「提交」，等待明确结果后播放对应音效。
3. 点击浏览器工具栏中的 Tampermonkey 图标，找到本脚本，选择「打开音效设置」。

设置面板默认隐藏，关闭后可以通过脚本菜单再次打开。请避免同时启用多份相同脚本，以免重复播放。

### 开启或关闭音效

设置面板中的「启用音效」控制结果音效总开关，「通过 / Accepted」与「未通过 / Failed」前的勾选框分别控制两类音效。

也可以通过 Tampermonkey 菜单中的「音效开关（开 / 关）」快速切换。

### 使用自定义音频链接

1. 在对应结果的音源列表中选择「自定义音频链接…」。
2. 填入可以直接访问的音频文件地址，建议使用 HTTPS 链接。
3. 离开输入框后自动保存，点击「试听」检查效果。

请填写音频直链，而不是音乐网站的播放页面或网盘分享页面。能否播放取决于链接有效性、访问限制和浏览器支持的音频格式。使用外部音频链接时，浏览器会向该音源所在网站请求音频。

### 导入本地音频

点击对应结果旁的「上传文件」，选择本地音频即可。

- 单个文件不能超过 **6 MiB**，建议使用简短、音量适中的提示音。
- 支持的格式取决于浏览器，常见格式包括 MP3、WAV、OGG。
- 文件内容保存在当前浏览器的脚本存储中，不会上传到作者服务器。
- 更换浏览器、清除脚本存储或卸载脚本后，可能需要重新导入。

### 恢复默认

点击「恢复默认」，恢复内置音效、默认音量和开关设置。

## 脚本菜单

| 菜单项 | 作用 |

## 常见问题

### 运行或提交后没有声音

先通过脚本菜单试听，再检查音效开关、脚本音量、系统音量、标签页静音和自定义音源。

如果试听正常，但运行或提交后没有声音，可能是操作入口或结果面板未被识别。请提供页面链接、操作方式和实际结果文案。

### 浏览器阻止声音播放

出现「浏览器阻止了声音，点击此提示重试」时，点击提示尝试重播，也可以先打开设置面板手动试听。浏览器的自动播放限制仍可能影响声音播放。

### 自定义音频无法播放

确认链接直接返回音频文件，不需要登录、特殊请求头或临时授权；本地文件需确保完整且格式受浏览器支持。可以切回内置音效，判断问题是否来自音源。

### 连续两次都是通过，会播放两次吗？

如果页面能识别出两次独立操作与结果更新，脚本会分别播放。如果页面完全没有可识别的新结果变化，脚本可能保持安静，避免把旧结果误当成新结果。

### 快捷键触发的操作也支持吗？

脚本会尝试识别编辑器中部分常见的运行与提交快捷键。自定义快捷键或其他扩展触发的操作可能无法识别，遇到问题时可以先使用页面按钮确认。

### 排队或判题很久，会播放未通过音效吗？

不会仅因为等待较久就播放未通过音效。超过约两分钟仍未识别到最终结果时，本次等待会结束，不主动播放结果音效。
