# BiliBili 高级倍速功能

[Greasy Fork 安装](https://greasyfork.org/zh-CN/scripts/605307) · [GitHub 备用安装](https://raw.githubusercontent.com/TetoTheNeko/UserScript/main/Bilibili-Advanced-Speed.user.js) · [查看源码](../Bilibili-Advanced-Speed.user.js) · [反馈问题](https://github.com/TetoTheNeko/UserScript/issues/new/choose)

基于 TheBszk 的「BiliBili 高级倍速功能」1.9 版本修改，主要改善多标签页倍速相互影响的问题，并增加附加功能开关和输入保护。

## 主要功能

- 自定义播放器倍速列表，默认包含 `0.5、1、1.5、2、2.5、3、4` 倍速。
- 按标签页和视频／分 P 独立记忆倍速，减少多个视频页面之间的相互影响。
- 快捷键切换倍速，长按右方向键临时加速。
- 可分别开关 `Z` 字幕切换、`G` 网页全屏、`H` 宽屏和双击字幕复制。
- 可设置默认宽屏，显示按当前倍速折算的播放时间。
- 输入框、可编辑区域和中文输入法组合输入期间跳过调速等快捷键处理，减少输入干扰。

脚本匹配 B 站的 `/video/`、`/list/`、`/bangumi/play/`、`/cheese/play/` 和 `/festival/` 页面。能否正常工作仍取决于页面实际使用的播放器结构。

## 设置入口

安装并刷新视频页面后，打开播放器的 **倍速菜单 → 设置**。

- **自定义倍速列表**：使用英文逗号分隔，例如 `0.5,1,1.25,1.5,2,3`。
- **长按右光标键速度**：例如 `2` 表示固定 2 倍速，`2x` 表示当前速度的两倍；当前实现按整数解析该设置，建议填写正整数或正整数加 `x`。
- **快捷键切换自定义列表速度**：开启后，数字键按从小到大的自定义倍速列表选择对应项。
- **附加功能开关**：字幕快捷键、网页全屏快捷键、宽屏快捷键和字幕复制可分别关闭，首次使用默认开启。

点击设置窗口右上角的 **×** 自动保存。当前版本中的「接管音量控制」已禁用，不作为可用功能提供。

## 快捷键

| 操作 | 效果 |
| --- | --- |
| `Ctrl + ↑` / `Ctrl + ↓` | 切换到自定义列表中更高／更低的倍速 |
| 长按 `→`（约 0.5 秒后） | 临时加速，松开后恢复 |
| 按住数字键 `1`–`9` | 临时切换到对应倍速，松开后恢复 |
| 按住数字键 `0` | 临时切换到 0.5 倍速，松开后恢复 |
| `Ctrl + 数字键` | 设置并记忆对应倍速 |
| `Z` | 切换字幕，需开启对应开关且视频提供字幕 |
| `G` | 切换网页全屏，需开启对应开关 |
| `H` | 切换宽屏，需开启对应开关 |
| `F2` | 切换按倍速折算的播放时间显示 |
| 双击字幕 | 复制字幕，需开启对应开关且浏览器允许剪贴板写入 |

开启「快捷键切换自定义列表速度」后，数字键 `1` 对应列表中最小的倍速，依次递增；超出列表长度的数字键不生效，`0` 不再映射为 0.5 倍速。

## 倍速记忆说明

当前倍速使用 `sessionStorage`，按标签页及视频地址中的视频／分 P 标识区分。一般可在同一标签页刷新后保留；关闭标签页后的长期保存不作保证。复制标签页时，浏览器可能复制初始会话数据，后续调速仍分别保存。

自定义倍速列表和功能开关等设置使用 `localStorage`，由同一浏览器配置下的 B 站页面共享。浏览器存储不可用时，脚本会尝试在当前页面内记忆倍速。

## 常见问题

- **没有出现设置入口**：确认脚本已启用，刷新页面并等待播放器加载；检查脚本管理器是否有在当前网站运行的权限。
- **快捷键冲突或倍速被改回**：尝试只启用本脚本，关闭其他倍速脚本或相关扩展后复现。
- **字幕复制失败**：检查视频是否有字幕、对应开关是否开启，以及浏览器的剪贴板权限。
- **某类页面失效**：请提供页面链接和复现步骤。B 站播放器改版后可能需要适配。
