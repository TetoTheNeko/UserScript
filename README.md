## 如何安装 / 使用？

1. 在浏览器中安装 [Tampermonkey（篡改猴）](https://www.tampermonkey.net/) 脚本管理器。
2. 点击表格中的「安装」，在 Greasy Fork 页面点击「安装此脚本」，按提示确认。
3. 刷新对应网站页面即可使用，具体功能与设置见各脚本的说明。
